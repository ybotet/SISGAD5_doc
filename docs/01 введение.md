## Общее описание бизнеса

### Система управления инцидентами для ETECSA

ETECSA (Empresa de Telecomunicaciones de Cuba S.A.) — государственная телекоммуникационная компания Кубы. Подразделение DAG5 (Dirección de Atención Gubernamental №5) отвечает за установку, обслуживание и ремонт телекоммуникационных услуг для государственных и корпоративных клиентов.
В настоящее время процессы управления инцидентами выполняются вручную и неорганизованно:

- Информация хранится в нескольких файлах Microsoft Access, разбросанных по сетевым папкам
- Отсутствует журнал аудита, позволяющий отследить, кто, когда и что изменил
- Статистические отчеты формируются вручную в Excel, что вызывает задержки
- Отсутствие интеграции между отделами (операции, продажи, кадры, логистика) приводит к дублированию информации и ошибкам
- Доступ к информации ограничен из-за использования файлов Access, которые не работают в операционных системах Linux

### Цель проекта:

Разработать современную, централизованную и безопасную веб-платформу, которая автоматизирует полный цикл управления инцидентами: от приема звонка клиента до закрытия тикета и формирования аналитических отчетов.

### Ключевые характеристики предметной области:

| Характеристика                      | Описание                                                                                                                                        |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Высокий объем инцидентов**        | Отдел получает сотни звонков ежедневно с сообщениями о сбоях телефонной связи, интернета и телевидения                                          |
| **Множество ролей пользователей**   | Различные профили с конкретными обязанностями: линейные специалисты, супервизоры, редакторы справочников, администраторы системы                |
| **Процессы со строгим SLA**         | Тикеты должны решаться в установленные сроки (например, диагностика за 10 минут, закрытие за 72 часа)                                           |
| **Внешняя техническая диагностика** | Диагностические тесты проводятся с помощью внешних инструментов; результаты вводятся в систему вручную                                          |
| **Сложная классификация**           | Инциденты классифицируются по типу услуги (телефония, телефонная линия, телефонная доска), затронутому оборудованию, географической зоне и т.д. |
| **Прослеживаемость и аудит**        | Все критические действия должны регистрироваться для соблюдения требований безопасности и контроля                                              |
| **Управленческая отчетность**       | Супервизорам необходимы интерактивные дашборды и статистические отчеты для принятия решений                                                     |
| **Интеграция между отделами**       | Информация должна автоматически передаваться между отделами операций, продаж, логистики и кадров                                                |
| **Кроссплатформенный доступ**       | Система должна быть доступна из любого браузера, независимо от операционной системы (Windows, Linux, macOS)                                     |
