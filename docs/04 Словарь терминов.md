# Словарь терминов

## 1. Основные сущности

| Термин                                      | Определение                                                                                                                                                                       |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Клиент**                                  | Физическое или юридическое лицо, которое заключает договор на телекоммуникационные услуги с ETECSA. Содержит идентификационные данные, контактную информацию и адрес              |
| **Тикет**                                   | Уникальная запись об инциденте или жалобе. Содержит всю информацию от создания до закрытия: данные клиента, диагноз, ремонт, использованные материалы                             |
| **Инцидент**                                | Перерыв, ухудшение качества или сбой телекоммуникационной услуги, о котором сообщил клиент                                                                                        |
| **Диагноз**                                 | Результат технического анализа, который определяет корневую причину инцидента и определяет, требуется ли ремонт на месте                                                          |
| **Тест**                                    | Набор технических измерений, выполняемых для диагностики инцидента (ping, задержка, потеря пакетов, SNR и т.д.)                                                                   |
| **Ремонт**                                  | Комплекс технических работ, выполняемых на месте для восстановления услуги                                                                                                        |
| **Назначение**                              | Связь между тикетом и полевым техником. Означает, что у техника есть тикет, ожидающий ремонта                                                                                     |
| **Материал**                                | Деталь, компонент или расходный материал, использованный во время ремонта. Может быть запасной частью, кабелем, разъемом и т.д.                                                   |
| **Приоритет**                               | Уровень срочности, присвоенный тикету согласно матрице критичности. Определяет порядок обработки                                                                                  |
| **SLA (Соглашение об уровне обслуживания)** | Определяет максимально допустимое время для диагностики, назначения, ремонта и общего решения в зависимости от приоритета тикета. Используется для расчета метрики соблюдения SLA |

## 2. Акторы

| Актор                             | Определение                                                                                                                                          |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Тестировщик**                   | Оператор первой линии. Принимает звонки, регистрирует клиентов, создает тикеты, проводит диагностику, регистрирует полевые работы и закрывает тикеты |
| **Редактор**                      | Администратор справочников. Управляет номенклаторами (классификации, типы линий, оборудование, типы неисправностей) и корректирует данные клиентов   |
| **Супервизор**                    | Руководитель операций. Назначает техников на тикеты, управляет назначениями, формирует отчеты, проводит аудит качества                               |
| **Администратор**                 | Системный администратор. Управляет пользователями, ролями и разрешениями. Наследует все возможности супервизора                                      |
| **Полевой техник**                | Персонал, выполняющий ремонт на месте. Не взаимодействует с системой напрямую; сообщает о выполненных действиях тестировщику                         |
| **Материальный менеджер**         | Ответственный за регистрацию материалов, использованных в ремонтах, и контроль запасов                                                               |
| **Неавторизованный пользователь** | Клиент, который звонит по телефону с сообщением о неисправности, не имея авторизации в системе                                                       |

## 3. Статусы тикета

| Статус                                               | Описание                                                                                  |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **Новый**                                            | Тикет создан, ожидает диагностики                                                         |
| **На диагностике**                                   | Выполняются технические тесты                                                             |
| **Требуется ремонт**                                 | Диагноз завершен, требуется ремонт на месте                                               |
| **Ожидает назначения**                               | Тикет готов к назначению техника                                                          |
| **Ремонт назначен**                                  | Техник назначен, ремонт ожидает выполнения                                                |
| **Ремонт завершен - ожидает регистрации материалов** | Техник сообщил о завершении работ. Ожидает регистрации материалов материальным менеджером |
| **Ожидает закрытия**                                 | Материалы зарегистрированы. Тикет готов к закрытию                                        |
| **Быстрое решение**                                  | Инцидент решен без выездного ремонта (удаленно)                                           |
| **Закрыт**                                           | Тикет завершен. Зарегистрированы решение, материалы и время                               |
| **Ожидание**                                         | Тикет ожидает какого-либо внешнего действия или дополнительной информации                 |
| **Ожидание техника**                                 | Нет доступных техников. Тикет в очереди                                                   |
| **Проверка супервизором**                            | Тикет с проблемой (неполный диагноз, неудачный ремонт). Супервизор анализирует            |

## 4. Номенклаторы (справочники)

| Номенклатор           | Описание                                                                                                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Тип инцидента**     | Определение инцидента, которое предоставляет пользователь при сообщении о проблеме. Примеры: шум на линии, отсутствие тона, нестабильный интернет, нет синхронизации и т.д.            |
| **Ключ**              | Детальный код, с помощью которого сотрудники классифицируют тип инцидента. В процессе эволюции тикета этот ключ может обновляться по мере уточнения диагноза                           |
| **Станция**           | Телефонные станции, с которых предоставляются телекоммуникационные услуги. Каждая станция имеет физическое расположение и обслуживает определенную географическую зону                 |
| **Рабочая группа**    | Определение области или команды, к которой принадлежит сотрудник. Позволяет организовать техников по специализации, зоне или типу услуги                                               |
| **Кабель**            | Тип кабеля, установленного для предоставления телекоммуникационной услуги. Примеры: медный кабель (витая пара), коаксиальный кабель, одномодовая оптоволокно, многомодовая оптоволокно |
| **Тип линии**         | Классификация линий связи по технологии: медь, оптоволокно, радиорелейная линия                                                                                                        |
| **Процедуры ремонта** | Стандартные действия, которые могут выполнять техники: замена кабеля, замена модема, переподключение, сращивание оптоволокна и т.д.                                                    |
| **Материалы**         | Каталог деталей и компонентов: кабели, разъемы, модемы, блоки питания, сплиттеры и т.д.                                                                                                |
| **Приоритеты**        | Уровни приоритета (1-5) с определенным временем реакции                                                                                                                                |

## 5. Бизнес-правила

| ID         | Бизнес-правило                                                             |
| ---------- | -------------------------------------------------------------------------- |
| **БП-001** | Диагностика должна быть завершена максимум за 10 минут                     |
| **БП-002** | Если причина не определена, требуется эскалация супервизору                |
| **БП-003** | Техник не может иметь более 8 активных назначений одновременно             |
| **БП-004** | Время полевых работ должно регистрироваться для расчета производительности |
| **БП-005** | Нельзя закрыть тикет без регистрации использованных материалов             |

## 6. Ключевые метрики

| Метрика                 | Descripción                                                         |
| ----------------------- | ------------------------------------------------------------------- |
| **Время диагностики**   | Время от статуса "На диагностике" до регистрации диагноза           |
| **Время назначения**    | Время от статуса "Требуется ремонт" до назначения техника           |
| **Время ремонта**       | Время от статуса "Ремонт назначен" до регистрации завершения работ  |
| **Общее время решения** | Время от создания тикета до закрытия                                |
| **Соблюдение SLA**      | Процент тикетов, закрытых в установленные сроки согласно приоритету |
