# 7. Матрица трассируемости

_(Matriz de Trazabilidad)_

---

## 7.1. Что такое матрица трассируемости?

_(¿Qué es la matriz de trazabilidad?)_

Матрица трассируемости — это таблица, которая показывает связи между:

- **Требованиями** (из карточки проекта и user stories)
- **Прецедентами** (из диаграммы случаев использования)
- **Классами** (из диаграммы классов)

Цель: убедиться, что все требования покрыты функциональностью системы и реализованы в модели классов.
_(Objetivo: asegurar que todos los requisitos están cubiertos por la funcionalidad del sistema y están implementados en el modelo de clases.)_

## 7.8. Заключение

_(Conclusión)_

Все требования, выявленные на этапе предпроектного обследования, покрыты:

- **Прецедентами** — каждый сценарий использования системы реализован в виде одного или нескольких прецедентов
- **Классами** — каждая функциональность обеспечена соответствующими классами, их атрибутами и методами

Архитектурные требования (кроссплатформенность, централизованное хранение данных) реализованы на уровне архитектуры системы и не требуют отображения в диаграммах классов.

Матрица трассируемости подтверждает, что модель классов полностью соответствует требованиям и может служить основой для проектирования API и базы данных.

_(Todos los requisitos identificados en la etapa de análisis están cubiertos por:_

- **_Casos de uso_** _— cada escenario de uso del sistema está implementado como uno o más casos de uso_
- **_Clases_** _— cada funcionalidad está soportada por las clases correspondientes, sus atributos y métodos_

_Los requisitos arquitectónicos (multiplataforma, almacenamiento centralizado de datos) se implementan a nivel de arquitectura del sistema y no requieren representación en los diagramas de clases._

_La matriz de trazabilidad confirma que el modelo de clases es completamente consistente con los requisitos y puede servir como base para el diseño de API y base de datos.)_
