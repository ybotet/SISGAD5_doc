# 15. Клиент-серверная подсистема
_(Sistema cliente-servidor)_

---

## 15.1. Введение
_(Introducción)_

В данной практической работе проектируется клиент-серверная подсистема корпоративной системы. Определены границы контура, спроектировано API, спецификация OpenAPI, модель данных, безопасность, наблюдаемость и тесты.

_(En esta práctica se diseña la subsistema cliente-servidor del sistema corporativo. Se definen los límites del contorno, se diseña la API, la especificación OpenAPI, el modelo de datos, la seguridad, la observabilidad y las pruebas.)_

---

## 15.2. Определение границ клиент-серверного контура
_(Definición de los límites del contorno cliente-servidor)_

### 15.2.1. Выбранные операции (минимум 6)
_(Operaciones seleccionadas - mínimo 6)_

| №   | Операция _(Operación)_                   | Эндпоинт _(Endpoint)_             | Метод _(Método)_ | Роль _(Rol)_            |
| --- | ---------------------------------------- | --------------------------------- | ---------------- | ----------------------- |
| 1   | Создание заявки _(Crear ticket)_         | `/api/v1/tickets`                 | POST             | Тестировщик             |
| 2   | Получение заявки _(Obtener ticket)_      | `/api/v1/tickets/{id}`            | GET              | Тестировщик, Супервизор |
| 3   | Список заявок _(Listar tickets)_         | `/api/v1/tickets`                 | GET              | Тестировщик, Супервизор |
| 4   | Назначение техника _(Asignar técnico)_   | `/api/v1/tickets/{id}/asignacion` | PUT              | Супервизор              |
| 5   | Регистрация теста _(Registrar prueba)_   | `/api/v1/tickets/{id}/prueba`     | POST             | Тестировщик             |
| 6   | Регистрация работы _(Registrar trabajo)_ | `/api/v1/tickets/{id}/trabajo`    | POST             | Тестировщик             |
| 7   | Закрытие заявки _(Cerrar ticket)_        | `/api/v1/tickets/{id}/cerrar`     | PUT              | Тестировщик             |
| 8   | Список материалов _(Listar materiales)_  | `/api/v1/materiales`              | GET              | Материальный менеджер   |
| 9   | Обновление запасов _(Actualizar stock)_  | `/api/v1/materiales/{id}/stock`   | PUT              | Материальный менеджер   |
| 10  | Аутентификация _(Autenticación)_         | `/api/v1/auth/login`              | POST             | Все                     |

**Всего:** 10 операций

### 15.2.2. Допущения
_(Suposiciones)_

- Интеграции с внешними системами на первом этапе отсутствуют
- Все операции требуют аутентификации (кроме `/login`)
- Авторизация проверяется по ролям JWT токена

## 15.3. Проектирование API и контрактов
_(Diseño de API y contratos)_

### 15.3.1. Единый формат успешного ответа
_(Formato único de respuesta exitosa)_

```json
{
  "success": true,
  "data": { ... },
  "timestamp": "2024-01-01T00:00:00Z"
}
```

### 15.3.2. Единый формат ошибки
_(Formato único de error)_

```json
{
  "success": false,
  "error": {
    "code": "BAD_REQUEST",
    "message": "Описание ошибки",
    "details": {},
    "timestamp": "2024-01-01T00:00:00Z"
  }
}
```

### 15.3.3. Коды ошибок
_(Códigos de error)_

| Код (Código) | Значение (Significado) | Условие (Condición)                          |
| ------------ | ---------------------- | -------------------------------------------- |
| 400          | Bad Request            | Неверные входные данные                      |
| 401          | Unauthorized           | Отсутствует или неверный токен               |
| 403          | Forbidden              | Недостаточно прав                            |
| 404          | Not Found              | Ресурс не найден                             |
| 409          | Conflict               | Конфликт версий (оптимистическая блокировка) |
| 500          | Internal Server Error  | Внутренняя ошибка сервера                    |

## 15.5. Модель данных и ограничения
(Modelo de datos y restricciones)

### 15.5.1. Схема базы данных
(Esquema de base de datos)

Диаграмма ERD и структура таблиц уже представлены в Практической работе №5.

**Основные таблицы:**

| Таблица (Tabla) | Описание (Descripción)                 |
| --------------- | -------------------------------------- |
| `bd_mp`         | Заявки, телефоны, линии, тесты, работы |
| `bd_users`      | Пользователи, роли, сессии             |
| `bd_materiales` | Материалы, запасы                      |

### 15.5.2. Ограничения целостности
(Restricciones de integridad)

| Ограничение (Restricción)                         | Тип (Tipo)                   |
| ------------------------------------------------- | ---------------------------- |
| `id_клиента` в Тикет должен существовать в Клиент | Внешний ключ (Foreign Key)   |
| `email` в Пользователь должен быть уникальным     | Уникальный ключ (Unique Key) |
| `prioridad` должен быть между 1 и 5               | Проверка (Check)             |

## 15.6. Безопасность взаимодействия
(Seguridad de la interacción)

### 15.6.1. Аутентификация (JWT)
(Autenticación - JWT)

| Параметр (Parámetro)       | Значение (Valor)                |
| -------------------------- | ------------------------------- |
| Алгоритм (Algoritmo)       | HS256                           |
| Срок действия (Expiración) | 1 час (1 hora)                  |
| Хранение (Almacenamiento)  | `Authorization: Bearer <token>` |

### 15.6.2. Роли и права доступа
(Roles y permisos)

| Роль (Rol)            | Доступные операции                                           |
| --------------------- | ------------------------------------------------------------ |
| Тестировщик           | Чтение/создание/изменение заявок, регистрация тестов и работ |
| Супервизор            | Назначение техников, аудит, отчеты                           |
| Материальный менеджер | Управление материалами и запасами                            |
| Администратор         | Управление пользователями                                    |

### 15.6.3. Требования к TLS
(Requisitos TLS)

- В производственной среде используется HTTPS (TLS 1.2+).
- В среде разработки допускается HTTP.

### 15.6.4. Аудит действий
(Auditoría de acciones)

| Событие (Evento)       | Логируется (Se loguea)                       |
| ---------------------- | -------------------------------------------- |
| Создание заявки        | Пользователь, дата, ID заявки                |
| Изменение статуса      | Пользователь, дата, старый/новый статус      |
| Регистрация материалов | Пользователь, дата, ID материала, количество |
